# ระบบบันทึกกิจกรรมเจ้าหน้าที่ไอที (IT Activity Log)

ระบบใหม่ทั้งหมดใน `D:\AI-Generated\zcode\it-activity` (ปัจจุบันโฟลเดอร์ว่าง) สำหรับให้เจ้าหน้าที่ไอทีบันทึกกิจกรรมการทำงานรายชั่วโมงแยกรายบุคคล

## Tech Stack
- **Next.js 15 (App Router) + TypeScript** — deploy บน Vercel ได้โดยตรง
- **TailwindCSS** — ทำ responsive (มือถือ/แท็บเล็ต/คอม) และ UI ภาษาไทยทั้งระบบ
- **Supabase** — Postgres (เก็บข้อมูล) + Auth (login เจ้าหน้าที่) + Storage (แนบรูป/เอกสาร)
- **ExcelJS** — export รายงาน Excel

## โครงสร้างฐานข้อมูล (Supabase)
| ตาราง | เนื้อหา |
|---|---|
| `profiles` | ชื่อ-สกุล, email, role (`admin`/`staff`), สถานะใช้งาน — เชื่อมกับ `auth.users` ผ่าน trigger |
| `categories` | หมวดงาน (ระบบเครือข่าย, ติดตั้งโปรแกรม, ประชุม, ซ่อมบำรุง, อื่นๆ) — แอดมินเพิ่ม/แก้ไข/ปิดใช้งานได้ |
| `activities` | วันที่, เวลาเริ่ม-สิ้นสุด, ช่วงเวลา (ใน/นอกเวลาทำการ — คำนวณอัตโนมัติจากเวลา อ้างอิงเวลาทำการ 08:30–16:30 ปรับได้, user แก้ทับได้), user_id, category_id, รายละเอียดงาน |
| `attachments` | ไฟล์แนบต่อ activity (เก็บไฟล์จริงใน Supabase Storage bucket `attachments`) |

**Security (RLS):** เจ้าหน้าที่เห็น/แก้ไขได้เฉพาะบันทึกของตัวเอง, แอดมินเห็นทุกคนและจัดการหมวดงาน/รายชื่อได้, ปิดการสมัครสมาชิกเอง (แอดมินเป็นคนสร้างบัญชีให้)

## หน้าจอระบบ (UI ภาษาไทย, responsive)
1. **/login** — เข้าสู่ระบบด้วย email/password
2. **/** (Dashboard) — สรุปของตัวเอง: ชั่วโมงทำงานวันนี้/เดือนนี้, แยกใน-นอกเวลาทำการ, แยกตามหมวดงาน
3. **/activities** — รายการกิจกรรมของตัวเอง + กรองตามช่วงวันที่/หมวดงาน, ปุ่มเพิ่ม-แก้ไข-ลบ
   - ฟอร์มบันทึก: วันที่, เวลาเริ่ม-สิ้นสุด (ระบบคำนวณช่วงเวลาให้อัตโนมัติ), เลือกหมวดงาน, รายละเอียด, แนบไฟล์รูป/เอกสาร (มือถือถ่ายรูปแนบได้ผ่าน input capture) พร้อม preview รูป
4. **/reports** — สรุปสถิติ + เลือกช่วงเวลา + Export Excel (แอดมินเลือกดูได้ทุกคน, staff เห็นเฉพาะตัวเอง)
5. **/admin/categories** — จัดการหมวดงาน (แอดมินเท่านั้น)
6. **/admin/staff** — เพิ่ม/แก้ไขรายชื่อเจ้าหน้าที่, สร้างบัญชี login, กำหนด role (แอดมินเท่านั้น)

## สิ่งที่จะส่งมอบ
1. โปรเจกต์ Next.js สมบูรณ์ (source code ทั้งหมด)
2. `supabase/migration.sql` — script สร้างตาราง, RLS policy, trigger, storage bucket รันครั้งเดียวใน Supabase SQL Editor
3. `.env.example` + คู่มือ setup สั้นๆ (สร้าง Supabase project → รัน SQL → เอา URL/Key มาใส่ → ตั้งค่า Vercel env → deploy)
4. บัญชี admin แรก: สร้างผ่านหน้า setup ครั้งแรก หรือให้คำแนะนำการสร้างใน Supabase Dashboard
